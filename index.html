An invoicing app for small businesses. You add clients, build invoices with line items, download a PDF, and send a Paystack payment link. When the client pays, the invoice updates itself, and no one has to confirm it by hand.

I designed the data model, the security rules and the payment flow, and used AI tools to speed up the interface code. I wrote and debugged the backend functions and tested the security myself.

It runs in Paystack test mode, so no real money moves.

About

I build web apps, and I care about the parts users never see.

I studied Computer Science at the University of Jos and graduated in 2025. I started in IT support at the Industrial Training Fund, helping staff fix real problems, and moved from there into building software.

My biggest build so far is KudiFlow. Getting a payment link to work was the easy part. The harder part was making sure each user only sees their own data, that totals are calculated on the server, and that a payment can’t be counted twice. Along the way I debugged CORS errors, function routing and webhook delivery, and I came out knowing how the pieces fit together.

I use AI tools every day to move faster, and I read and test what they produce before it ships.
